# 欧阳画板 · 提示词绘画工作台

> 当前版本 **v1.10.1** · 更新历史见 [CHANGELOG.md](CHANGELOG.md)

轻量级纯网页 AI 绘图工具：接 OpenAI 兼容画图 API 出图，左侧词库把常用提示词分组收藏，
**点一下 = 追加到对话框（不替换）**，像搭积木一样组合出图。

纯静态站点，无框架、无依赖、无构建、无后端，直接丢到 GitHub Pages 就能用。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🧩 追加式调用 | 点击词卡插入光标处，自动补逗号，可去重、可撤销（Ctrl+Shift+Z） |
| 🗂 分组词库 | 分组增删改名换色、卡片拖拽排序、搜索、按使用次数/时间排序 |
| 🎨 画图 API | OpenAI 兼容 `/images/generations`，可配 baseURL/Key/模型/尺寸/质量/负向词/自定义 JSON |
| 🛡 参数自动降级 | 接口 400 报错点名某参数（如 aspect_ratio）时，自动摘掉该参数重试一次 |
| 📋 模型列表 | 一键从 `/models` 拉取可用模型，搜索过滤、点击选用 |
| 🖼 图生图 | 上传/拖拽/粘贴参考图，参考强度可调，字段名可映射（SD WebUI 兼容），输出尺寸可跟随原图 |
| 🌍 中译英 | 一键把提示词翻译成英文，可复用画图接口的 Key（走 `/chat/completions`），替换/追加/复制三种模式 |
| ✨ AI 帮写 | 一句话描述需求，按三档深度（整理优化 / 细节扩充 / 深度具象化）生成中文提示词，可编辑后覆盖或追加 |
| ⧉ 组合出图 | A 组（主体）× B 组（姿势）笛卡尔积批量生成，清单可单条开关 |
| ⤓ 批量下载 | 全选后手动取消部分，确认逐个下载 |
| ☁️ GitHub 云同步 | 词库存进你自己的仓库（一个 JSON），换设备登录即同步，含分步「测试连接」诊断 |
| 📤 导入导出 | 一键导出/导入 JSON 备份，兼容旧格式 |
| 🗑 清空历史 | 历史区一键清空，二次确认并显示条数与原图数；只删历史与本地图片，不动词库/配置/云同步 |
| 🌗 浅色 / 深色 | 双主题手动切换并记住；深色为石墨底 + 青色主强调，浅色为冷灰底 + 深青主色 |
| 📱 移动端适配 | 次要操作收进 ⋯ 底部菜单，顶栏不换行，零横向溢出 |

## 🖼 图生图使用

1. 点画布上方「🖼 图生图」上传图片，或直接 **Ctrl+V 粘贴**、拖拽到参数面板的投放区
2. 调「参考强度」：越低越自由发挥，越高越贴近原图
3. 输出尺寸默认跟随原图，可关闭后自定
4. 补充提示词（如 "watercolor style"），开始绘制

参考图字段默认 `image` + `strength`，SD WebUI 用户改成 `init_images` + `denoising_strength` 并把传递方式切为「纯 base64」。超过 2048px 的图会自动等比压缩。参考图只存在本机内存，刷新即清空。

## ✨ AI 帮写提示词

点底栏「✨ AI 帮写」（手机端在 ⋯ 菜单），用一句日常语言描述想要的画面，AI 会整理成可直接绘图的中文提示词。
面板顶部可切换三档加工深度：

| 等级 | 适合场景 | 加工方式 |
|---|---|---|
| ① 整理优化 | 你已经想清楚，只想理顺表达 | 调整语序、消除重复、理顺已有关系，几乎不新增设定 |
| ② 细节扩充（默认） | 想要更完整的画面 | 在保留原意的前提下补充服装、动作、环境、光线、构图、材质等可见细节 |
| ③ 深度具象化 | 描述还很模糊，需要能直接画出来 | 把服装结构、手部与物体接触、重心与腿脚、光影层次拆成具体描述，并做人体合理性自检 |

- 三档共用设置 →「翻译」里的对话接口（Base URL / Key / 模型），留空则回退画图接口；不额外发请求，**切换等级不会自动重新生成**
- 生成结果可直接编辑；点「填入提示词」时，空输入框直接填入，已有内容会询问「覆盖 / 追加 / 取消」
- 覆盖可用 `Ctrl + Shift + Z` 撤销；档位与草稿在关闭面板后保留，刷新页面回到默认二级

## 🚀 部署到 GitHub Pages

1. 新建一个 GitHub 仓库，把 `index.html`、`styles.css`、`app.js`、`icons/` 传上去。
2. 仓库 **Settings → Pages** → Source 选 `main` 分支 `/ (root)` → Save。
3. 一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

本地直接双击 `index.html` 也能用（API Key 建议在 https 环境下使用）。

## ☁️ 配置云同步（可选但强烈推荐）

1. GitHub → Settings → Developer settings → **Personal access tokens → Fine-grained tokens** → Generate。
2. Repository access 选你存词库的仓库（可以就是 Pages 这个仓库），权限勾选 **Contents: Read and write**。
3. 打开网站 → 右上角 ⚙ 设置 → **云同步 · GitHub**：
   - 填 Owner（用户名）、Repo（仓库名）、分支（一般 `main`）、路径（默认 `prompts.json`）、Token。
4. 点 **「🔌 测试连接」** 先验证一遍——它会分三步检查 Token、仓库、路径，并逐项告诉你结果，填错了不用猜。
5. 点 **「上传到云端」** 完成首次同步；之后改动会自动延迟上传（可在设置里关掉）。
6. 换设备打开同一网址，填好同样的信息，点 **「从云端拉取」** 即可（合并去重，不覆盖本地）。

两个同步开关：

| 开关 | 默认 | 作用 |
|---|---|---|
| 修改后自动上传 | 开 | 改动词库后约 2.5 秒自动推送一次（有防抖） |
| 启动时自动拉取合并 | 关 | 每次打开页面与云端合并一次，有新增会提示差异摘要。默认关，避免两台设备同时改动造成静默分叉 |

> Token 只存在你本机浏览器的 localStorage，请求由浏览器直连 GitHub，不经过任何第三方。
> 公开仓库也可以不填 Token 只读拉取（勾选「公开仓库」）。

## 🔑 接入画图 API

设置 → 接口配置：

- **Base URL**：填到 `/v1` 为止，如 `https://api.openai.com/v1`（会自动拼 `/images/generations`）
- **API Key**：`sk-…`
- **模型**：`gpt-image-1` / `dall-e-3` / 硅基流动 `Kwai-Kolors/Kolors` / 智谱 `cogview-4` 等
- 不同厂商参数名不一致时，用「高级 · 自定义请求参数」里的字段映射和额外 JSON 兜底

内置「快填预设」：OpenAI / 硅基流动 / 智谱 / 通义 / 本地自建。

## 📝 数据存放

- 词库、接口配置、主题、界面偏好 → `localStorage`（键名 `pp.*`，与旧版本一致）
- 生成历史 → `IndexedDB`（库名沿用旧库名，老数据无需迁移）
- 可选：GitHub 仓库中的一个 JSON 文件（云同步）

> 名称从 Prompt Painter 改为「欧阳画板」时，**存储键名、数据字段、IndexedDB 库名均未改动**，
> 因此升级后原有词库、配置、历史记录都会照常读到。
